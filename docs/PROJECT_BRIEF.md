# Landing Page - Jefferson Capela

## Objetivo

Preparar a base de um projeto Next.js para uma landing page mobile-first de Jefferson Capela, despachante armamentista com foco em assessoria para concessao de CR/CAC.

Nesta etapa, as secoes visuais da pagina nao devem ser implementadas.

## Stack

- Next.js com App Router
- TypeScript
- Tailwind CSS
- Exportacao estatica para hospedagem em GitHub Pages

## Direcao visual futura

Preto e grafite como base, dourado metalico como destaque e branco para textos. A interface deve ter aparencia premium de miniaplicativo, com botoes grandes, textos legiveis, cards arredondados e bordas douradas finas.

Evitar aparencia de e-commerce de armas, excesso de elementos militares e textos pequenos.

## Regras de conteudo

- Nao inventar endereco, depoimentos, credenciais ou numeros.
- CTAs futuros devem gerar mensagens qualificadas para WhatsApp.
- Nao prometer aprovacao de nenhum processo.
- Prints em `public/references` sao apenas referencia de composicao, hierarquia, cores e UX.
