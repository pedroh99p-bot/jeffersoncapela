# Landing Page - Jefferson Capela

Base Next.js para landing page mobile-first de Jefferson Capela.

## Comandos

- `npm run dev`: ambiente local
- `npm run lint`: ESLint
- `npm run build`: build estatico em `out/`

Para GitHub Pages com caminho de repositorio, defina `NEXT_PUBLIC_BASE_PATH`, por exemplo:

```bash
NEXT_PUBLIC_BASE_PATH=/jeffersoncapela npm run build
```
